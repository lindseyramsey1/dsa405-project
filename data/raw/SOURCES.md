# Data Sources

## BLS Average Hourly Earnings Data

File: `bls_hourly_earnings_raw.csv`

Source: U.S. Bureau of Labor Statistics (BLS), Current Employment Statistics (CES)

API: https://api.bls.gov/publicAPI/v2/timeseries/data/

Date retrieved: October 1, 2026

Description: Monthly average hourly earnings data for eight selected U.S. industries from January 2015 through December 2025. The file contains the raw observations retrieved from the BLS Public Data API before cleaning or transformation.
